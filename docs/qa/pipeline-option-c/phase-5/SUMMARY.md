# Phase 5 Summary — Pipeline Option C

Churches can fork `winners_default` into an owned definition and customize it:

- Admin/Pastor: Settings → **Membership Pipeline**
- Fork (idempotent), rename definition/stages, add custom stage keys
- `GET /follow-up/pipeline` returns `source: definition` after fork; Establishment tabs update immediately
